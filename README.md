# DayFlow Activity App 📅

A personal productivity Flutter app that helps you stay organized and focused throughout your day — built with Flutter and Hive local storage.

---

## 📱 About

DayFlow is designed for people who want a simple, lightweight way to manage their daily activities, track progress, and stay focused — without needing an internet connection. Everything is stored locally on your device using Hive.

---

## ✨ Features

- **Activity Management** — Add, edit, and delete daily activities with title, category, and scheduled time
- **Progress Tracking** — Mark activities as complete and visually track your daily progress
- **Study Timer** — Built-in Pomodoro-style study timer to stay focused during work or study sessions
- **Offline First** — All data stored locally with Hive, no internet required
- **Clean UI** — Minimal and intuitive interface designed for quick daily use

## 🚀 Getting Started

### Prerequisites
- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0

### Installation

1. Clone the repository
```bash
git clone https://github.com/kutubofficial/daily_activities_app.git
```

2. Navigate to the project directory
```bash
cd dayflow
```

3. Install dependencies
```bash
flutter pub get
```

4. Run the app
```bash
flutter run
```
